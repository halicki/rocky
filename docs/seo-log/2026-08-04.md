## Why the biggest pool was passed over: a real gap in Rule 1's action text

Tie-breaker #2 is "więcej wyświetleń", and by that reading `/surf-lesson-prices-bali/` (369 impressions at 10.1, 0.5% CTR) should win — it is also the more commercial surface. It was passed over for a reason worth recording, because it will recur:

**Rule 1's prescribed action requires an exact query** — "dokładne query w H2 i pierwszych 100 słowach", "anchor textem zawierającym query", "title i meta description zawierają dokładne query". That action is only executable if you know which query the page's impressions come from. For the prices page, you don't:

- its named price queries rank at **~42**, not 10 — `surfing lessons bali price` 13 impr @ **42.4**, `surf lesson canggu price` 3 @ **41.7**, `how much are surf lessons in bali` 4 @ 29.5

Writing a price-focused H2 would therefore target queries the page does *not* rank for, while the queries it does rank for stay unaddressed. The same audit kills `/blog/kids-surf-lessons-canggu/` (67 impr @ 8.1): the only kid-related query in 125 returned is `canggu with kids`, 2 impressions at position 54.

`/blog/private-vs-group-surf-lesson-bali/` is the highest-volume in-band page where page-level position and a known target query actually agree: the slug's PLAYBOOK target query, the page at 15.7, and `group surf lessons` (4 impr @ 21) all point at the same intent. **Known query beat raw volume.** Tie-breaker #4 (never been the target of any action — created 04-27, untouched for 99 days) points the same way.

### Built to narrow, not broaden — learning from the best-surf-school regression

`best-surf-school-bali-how-to-choose` is the loop's live cautionary tale: a Rule 1 section added on 07-23 preceded a slide from **12.5 → 22.2** across nine windows, and the standing diagnosis is that the added "by surfer type" section pulled the page toward a broader, more competitive intent than the one it was ranking for.

Today's section is deliberately the opposite shape. It adds **no new topic** — it is a side-by-side comparison table of the three formats the post already discusses (price, waves caught, waves actually coached, cost per coached wave, board swap, water time), plus three paragraphs interpreting it. Every sentence stays inside "private vs group surf lessons in Bali". The table is also structured, extractable content of exactly the kind Google lifts into featured snippets for "X vs Y" queries, which is the mechanism most likely to move a page sitting at 15.7.

Editorial honesty preserved per house style: the cost-per-coached-wave framing favours the private lesson, so the section immediately concedes that the metric only matters if your goal is to *learn* — and that for a fun morning in the water, a $25 group lesson is unbeatable. No upsell.
