## Selection: the rank-bound / CTR-bound split, and a fix for yesterday's PLAYBOOK gap

Yesterday's log recorded that Rule 1's action text ("dokładne query w H2 i pierwszych 100 słowach", "anchor textem zawierającym query", "title i meta description zawierają dokładne query") is **inexecutable on a page whose driving query is invisible**, and that the site's largest in-band pools are exactly that. Today the same audit ran with a sharper instrument — **what share of the page's impressions are attributable to a named query**:

| Page | Impr | Named impr | Share | Verdict |
|---|---|---|---|---|
| `/surf-lesson-prices-bali/` | 341 | 13 (`surfing lessons bali price` @ **42.5**) | **4%** | Inexecutable — and the named query ranks 32 positions below the page, so it is a different cluster. |
| `/blog/kids-surf-lessons-canggu/` | 66 | 2 (`canggu with kids` @ 54) | **3%** | Inexecutable. |
| **`/blog/intermediate-surf-coaching-canggu/`** | **15** | **4** (`intermediate surf lessons` @ **22.5**) | **27%** | **Executable.** |

Twenty-seven percent is an order of magnitude better visibility than any larger pool offers, and the gap between query (22.5) and page (12.0) is ten positions inside a single intent — not the thirty-plus positions that marked the prices page's traffic as spillover from the Batu Bolong cluster. **This is the striking-distance mechanic in its literal form: pull one known query up toward the position the page already holds.**

The second filter that decided the run is worth recording, because it explains why four larger pages were skipped. There is a whole tier of in-band pages — `how-long-to-learn-surfing-bali` (34 impr @ 6.8), `what-to-bring-surf-lesson-bali` (31 @ 7.1), `best-time-to-surf-canggu` (30 @ 7.8), `/surf-lessons-canggu` (28 @ 9.0), `batu-bolong-surf-forecast` (27 @ 7.5) — all sitting at **positions 6.8–9.0 with zero clicks**. Those pages are not rank-bound. Rank is already fine; the snippet is the binding constraint, which is Rule 4's instrument, not Rule 1's. Adding 400 words to a page at 6.8 to move it to 6.2 buys nothing.

Among genuinely **rank-bound** in-band pages (position 10+), the field is: private-vs-group (ortho-locked), kids-safety (do-not-re-strike, recovering), prices (anonymised), the blog index (not a content target) — and intermediate-coaching. It is the only one left standing, and it happens to be the one that regressed this window.

Tie-breaker #4 does not apply cleanly (the page has been *edited* three times as a link source for orphan-wiring, on 07-13/07-20/07-26) but it has **never been the target of an action aimed at its own ranking** since it was created on 06-29.
