arithmetic closes by construction.** It cannot fail, so it was never evidence.

shown: **the 27 overlapping days were not revised by Google between yesterday's snapshot and
today's.** 52 − 2 + 5 = **55**; 4967 − 230 + 199 = **4936**. The roll is clean *as a finding*,
for the first time in the series. Recommended as standing practice; it costs one extra API call.
