## Proposed PLAYBOOK v4 amendment (not written — one run's evidence is not enough)

**Rule 1, gate 1 — apply the band test to the target query when the page aggregate is dominated by a different query family.**

Today's case is the first where the page-level band gave the wrong answer for a defensible reason. A page whose aggregate is pulled below 10 by a large won-but-unconvertible query family is *not* the CTR-bound page the band was narrowed to exclude on 08-10; those eight pages were at 6.7–9.9 across their *whole* query set. Proposed wording: *"If ≥50% of the page's impressions come from a query family ranking in a different band than the target query, evaluate the band on the target query."*

**Deliberately not written today.** v3 exists because five amendments sat un-written while the loop acted under a broken rule — but it also exists because the loop repeatedly bent Rule 1's band to fit whatever it wanted to do. Writing this amendment on the same day I invoke it, before the strike has produced a single data point, is exactly that failure mode. **Revisit 08-22 with the result in hand:** if the strike works, the amendment is justified by outcome; if it fails, the deviation was the loop bending the rule again and the correct response is to tighten gate 1, not loosen it.
