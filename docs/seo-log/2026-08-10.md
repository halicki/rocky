### The sixth amendment's origin: a real canonical defect

Diagnostics for the Rule 1 target turned up the root cause of the duplicate-URL issue flagged on 08-09:

- `next.config.ts` sets **`trailingSlash: true`** — the server 308-redirects `/x` → `/x/`
- **all 40 canonical tags in the repo declare the slash-less form** (`alternates: { canonical: ".../blog/x" }`)

Google receives contradictory signals and has indexed inconsistently: `/blog/surf-coaching-video-analysis-canggu` reports in **both** forms simultaneously (15 impr @ 6.2 with slash, 5 @ 17.4 without), while `/blog/best-time-to-surf-canggu` (30 impr) and `/surf-lessons-canggu` (27 impr) are indexed **only** in the slash-less form.

`next.config.ts` is on the forbidden list, so the only legal fix is a canonical sweep — which the 3-file cap prohibited until today. Documented in v3 as the first scheduled sweep.
